# dotfiles

My personal Linux desktop configuration.

A collection of configuration files for a minimal and customizable Wayland desktop, mainly focused on aesthetics, usability, and a setup that feels comfortable for everyday use.

## What's included

* Hyprland
* Waybar
* Fastfetch
* Starship
* Zsh
* Alacritty
* Neovim
* Cava
* GTK configuration
* Other small utilities and scripts
